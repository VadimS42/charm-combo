# Where these come from

| Files | Pack | Licence |
|---|---|---|
| `rg_08 sg_19 mg_26 bg_16a pg_28 gg_27 dg_19 yg_27.png` | "MIX gems" (sent as `MIX_gems.rar`) | check the page it was downloaded from; credited in `data/credits.txt` |

| `kenney/*.png` | Game Icons by Kenney | CC0, see `kenney/LICENSE.txt` |

`tools/icon_packs/make_game_art.py` turns these into `art/gems`, `art/tiles`,
`art/frames` and `art/ui`. Not used (yet): the Celyanae Match-3 set (flat
style, doesn't match the painted gems) and game-icons.net (CC BY 3.0, needs
per-author credit if used).
